# Vrinda Store Data Analysis

## Project Overview
This project analyzes Vrinda Store's 2022 sales data using Microsoft Excel to identify customer patterns, sales trends, order performance, and business insights.

## Tool Used
- Microsoft Excel

## Project Structure
The Excel workbook contains the following sheets:

- **Vrinda Store** – Original store data
- **Cleaned Data** – Cleaned and prepared dataset for analysis
- **Pivots** – Pivot tables used for analysis
- **Vrinda StoreReport 2022** – Final annual report and dashboard

## Analysis Performed
- Sales analysis
- Customer analysis
- Order analysis
- Age-group analysis
- Category analysis
- Monthly sales and order analysis
- Sales dashboard
- Pivot table analysis

## Key Insights
- Women contribute **64% of total orders**.
- **Adults** are the largest customer segment.
- Women have higher orders across all age groups.
- **March** is the strongest month for sales and orders.
- The analysis highlights customer, category, channel, and sales trends.

## File
**Vrinda Store Data Analysis.xlsx**

## Objective
The objective of this project is to analyze store sales data and generate meaningful insights that can support better business and customer-focused decisions.
